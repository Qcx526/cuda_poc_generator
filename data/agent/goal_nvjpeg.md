# 研究目标

研究 NVIDIA nvJPEG 组件中的一个已披露缺陷（CVE-2026-65160，NVIDIA 2026-11-03 公告，
CWE-369 除零，影响为拒绝服务）。公告只给出这一句描述，没有函数、字段或输入形态。

你的任务不是必须复现它，而是把这个问题研究到"有证据的结论"：
- 查清这个公告到底说了什么，以及它对应的组件在本机的真实版本；
- 判断本机环境能否开展可评价的实验；能就做，不能就说清缺什么；
- 如果做实验，必须由你实际执行并保留可核验的过程，不能只写方案。

环境说明（只是事实，不是方法建议）：
- 这台 Windows 主机有 GPU、CUDA 工具链、Docker、Python、C/C++ 编译器；
- 工作区就是你当前目录，可以随意写文件、编译、运行；
- 允许联网查官方资料；不允许修改系统驱动或安装需要管理员权限的东西；
- 目标 DLL 可能不止一个版本，具体有哪些需要你自己确认。

结束时给出一段结论，必须写清：你做了什么、观察到什么、哪些是推测、哪些有证据、
还有什么没解决。
