# P4-S 实验结果：对照设计修复的 A/B 消融

报告语言：`zh-CN`。数据来自 2026-10-22 的两组独立运行，协议与产物均在仓库内。

## 1. 实验协议

| 项 | 设置 |
|---|---|
| 样本 | CVE-2024-0076（有规格）、CVE-2025-23338（无规格）、CVE-2025-23339（有规格） |
| 每 CVE 重复 | 3 次独立运行（`--repeat 3`） |
| 每轮迭代上限 | 2 |
| 模型 | deepseek-v4.1-flash，温度 0 |
| 判定 | 差分：恶意崩 + 良性净 + 对照未全崩 |
| A 组 | 修复前（对照只要求"改一个变量"） |
| B 组 | 修复后（对照必须**恢复到基线值**，且命名 `<field>_restored_<value>`） |

## 2. 结果

| CVE | A：success@3 | B：success@3 | 变化 | 规格 |
|---|---|---|---|---|
| CVE-2024-0076 | 2/3 | **3/3** | ↑ 33% | 100% |
| CVE-2025-23338 | 1/3 | **3/3** | ↑ 67% | 无 |
| CVE-2025-23339 | 2/3 | 2/3 | = | 100% |

**汇总**：A = 5/9（56%）→ B = 8/9（89%），**+33.3 个百分点，2 个提升、0 个退化**。

单次耗时（B 组）：0076 317s、23338 236s、23339 1115s（该 CVE 有一轮先 `HARNESS_STEP_FAILED`
再经反馈修正）。

## 3. 必须说清楚的三个局限

**① 样本量小。** 每组 9 次运行，5/9 与 8/9 的差异在统计上并不稳健，只能作为方向性证据。
要写进论文至少需要每 CVE 5 次、CVE 数 ≥10。

**② 存在混杂因素。** 有规格的两个 CVE（0076/23339）在 A、B 之间**规格里积累了
`history.observed`（实测会崩的变异点）**，所以它们的提升不能全部归因于对照修复。
唯一干净的是 **23338：无规格、无历史积累，1/3 → 3/3**，这一条才是对照修复的独立证据。

**③ 温度 0 不等于完全确定。** 服务端仍可能有非确定性；同一 CVE 的 3 次运行
并非逐字节相同的输入。

## 3.5 C 组结果：上一轮的 "+33 个百分点" 没有复现

C 组条件：**保留对照修复，冻结规格里积累的 observed 知识**（`--freeze-history`）。

| CVE | A（旧对照/无积累） | B（新对照/有积累） | C（新对照/冻结积累） |
|---|---|---|---|
| CVE-2024-0076 | 2/3 | 3/3 | **1/3** |
| CVE-2025-23338 | 1/3 | 3/3 | **3/3** |
| CVE-2025-23339 | 2/3 | 2/3 | **1/3** |
| **合计** | 5/9 = 56% | 8/9 = 89% | 5/9 = 56% |

三项事实：

1. **C 组与 A 组完全持平（5/9）**：只加"对照必须恢复基线值"这一条，看不出任何提升；
2. **B 组的 89% 无法在 C 组复现**：去掉积累知识后跌回 56%；
3. **23338（无规格、冻结对它是空操作）在 B 与 C 都是 3/3**，在 A 只有 1/3 ——
   它既没有规格也没有历史，唯一的变化是对照定义，但它的提升与 0076/23339 的下滑方向相反。

合理解释只有一个：**n=3 的波动压过了真实效应**。8/9 与 5/9 的差异在统计上不显著
（Fisher 精确检验 p ≈ 0.35），把它当成"改进有效"是过度解读。

**结论修正**：目前**没有证据**表明对照契约或知识积累带来了稳定提升；
现在的单次成功率约 50–60%，且方差极大。上一轮报告的 +33.3 个百分点应视为噪声范围内的波动。

## 4. 结论

- **对照修复的效果未确立**：C 组与 A 组持平，说明这条改动单独看没有可测收益；
- **知识积累的效果也未确立**：B 组的高值无法在 C 组复现；
- **真正确定的是方差**：同一个 CVE 在三次运行里可以 3/3 也可以 1/3，
  **n=3 不足以支撑任何改进结论**；
- 唯一稳定的观察：单次运行成功率约 50–60%，与早期"1/3"的估计一致。
